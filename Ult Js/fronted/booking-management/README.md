# Level Placement Test Booking System

React + Vite frontend matching the three supplied exam mockups (Booking List, Create Booking, Update Booking).

## Run
```bash
npm.cmd install
npm.cmd run dev
```
(Windows PowerShell: use `npm.cmd` if `npm` is blocked by script execution policy.)

## Included
- Exam `Resources` images copied into `public/resources/`
- Booking list, create, update, details and status change
- Payment slip file picker (frontend demo stores only its filename)
- Responsive layout and localStorage persistence

This is frontend-only. Real payment upload/verification, Zoom links, login and server storage require a backend.
